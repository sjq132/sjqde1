# 工业零部件质量智能检测系统

## 课程设计 · 制造智能技术

本项目为制造智能技术课程设计作业，主题为**通用工业零部件质量智能检测系统**。

### 项目简介
针对制造现场人工质检效率低、主观性强、易疲劳漏检等问题，构建一个基于深度学习的工业零部件表面缺陷自动检测原型系统。系统支持图片上传、缺陷自动定位与分类、检测结果可视化、历史记录查询与统计，形成从"上传→检测→存储→查询→统计"的完整业务闭环。

### 技术主线
- **任务范式**：目标检测（定位 + 分类），而非仅整图分类
- **核心模型**：YOLOv8（检测）+ ResNet-18（二次验证）+ Qwen2.5-VL（报告生成扩展）
- **系统形态**：完整 B/S 架构 Web 应用（Flask + 原生前端 + SQLite）
- **主数据集**：MVTec AD（通用工业零部件/纹理基准数据集）
